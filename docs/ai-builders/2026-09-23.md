**Madhu Guru, Sr Director of AI at Meta, previously at Google where he led Gemini, Veo and Nano Banana**

He respectfully disagrees with Ben Thompson on consumer agents: consumers do not have one relationship with "doing things". Browsing clothes can be entertainment, but hiring a roofer is miserable for most. Even with shopping, sometimes you want to browse for an hour, sometimes you want the right thing delivered ASAP. He says the counter-argument sounds like the early 2000s skepticism about buying clothes or a $500 TV online. Technology keeps giving you better ways of doing things, and for tasks like hiring a roofer, better means almost zero effort, so the latent demand for agents that remove this friction is immense.

他就 consumer agent 话题礼貌地不同意 Ben Thompson：消费者和 "把事情办完" 的关系并不是单一的。逛衣服可以是娱乐，但请屋顶工人对大多数人来说是折磨。即便是购物，有时你想逛一小时，有时你只想让对的东西尽快送到。他说反对者的论调像极了 2000 年代初 "谁会在线上买衣服/500 美元的电视" 的怀疑。技术一直在提供更好的做事方式，而对请屋顶工人这类任务，更好就意味着几乎零付出，因此消除这种摩擦的 agent 存在巨大的 latent demand。

**Guillermo Rauch, CEO of Vercel**

A substantial architecture post: Muse, Instinct, OpenClaw and Claude Code all have three key components, a brain (model and harness logic), hands (tools, computer, browser) and files (memories, skills, repos). The easy way is one stateful computer, but cost-efficient agents in the cloud require decoupling: the harness runs in Fluid compute with durable event logs via Workflow, hands become a browser fleet or a Sandbox, and what was missing was decoupled storage, which is why Vercel is introducing Drives, an external disk you can attach at will, enabling things like nightly memory consolidation cron jobs without booting the full agent. He adds that breaking the agent into independent parts not only cuts costs but massively improves security and auditability, to the point that he argues you cannot run a secure agent otherwise.

一篇重要的架构帖：Muse、Instinct、OpenClaw 和 Claude Code 都有三个关键组成部分，brain（模型与 harness 逻辑）、hands（tools、computer、browser）和 files（memories、skills、repos）。简单做法是一台有状态的计算机，但要在云端以高性价比运行 agent 就必须解耦：harness 跑在 Fluid compute 上，用 Workflow 保证 event log 在重启、发布、崩溃时持久；hands 可以是 Browserbase/Kernel 的 browser fleet 或 Sandbox 之类的 computer；缺的一直是存储的解耦，因此 Vercel 推出 Drives，可以随挂随取的 "外置磁盘"，让你不用启动整个 agent 就能跑夜间 memory consolidation 的 cron job。他补充说，把 agent 拆成独立部分不仅大幅优化成本，还极大提升安全与可审计性，他甚至认为不这样做就跑不了安全的 agent。

**Ryo Lu, designer of Cursor, Notion and Stripe, builder of startups**

A long essay on speed versus meaning: we worship efficiency, productivity and speed, but what is the point of endless production if there is no time left to think deeply? AI could be a new canvas for strange, personal, impossible things, yet so much of it is becoming slop factories. His core lines: the danger is not that AI makes us lazy, the danger is that AI makes us endlessly busy, giving us infinite production before we have found intention and infinite execution before we have developed taste. Maybe the real frontier is not more speed but discernment, knowing what not to make and when to stop. Tools should give us more life, not turn life into a tool.

一篇关于速度与意义的长文：我们崇拜 efficiency、productivity 和 speed，但如果连深度思考的时间都没了，无休止的生产还有什么意义？AI 本可以成为一张新画布，用来做怪异、个人化、不可能的东西，但如今太多东西变成了 slop 工厂。他的核心句：危险不在于 AI 让我们变懒，而在于 AI 让我们无休止地忙碌，让我们在找到 intention 之前就拥有无限的生产力，在养成 taste 之前就拥有无限的执行力。也许真正的 frontier 不是更快的速度，而是 discernment，知道什么不该做、何时该停下。工具应该给我们更多生活，而不是把生活变成工具。
