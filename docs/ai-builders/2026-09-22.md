## X/TWITTER

**Boris Cherny, Claude Code at Anthropic**

Two major posts. First, he used Opus 5.5 to formally verify the Claude Agent SDK using Lean: a couple of short prompts produced 16 PRs fixing various bugs and race conditions, and TLA+ also works well, sometimes combined with Lean to look for issues in data flow, concurrency and state management. He notes he knows neither language well but Claude is excellent at both, making this a practical way to find bugs a human probably would not have spotted, and asks whether formal verification is the future of coding, or at least of bug finding. Second, a benchmark: Opus 5.5 and Fable 5.1 each ported HAProxy from C to Rust. Both passed nearly all of HAProxy's tests, but Opus 5.5 finished in 9.5 hours versus 12, for 51% less cost.

两条重磅帖子。第一，他用 Opus 5.5 配合 Lean 对 Claude Agent SDK 做了 formal verification：几条简短 prompt 就产出了 16 个 PR，修复了各种 bug 和 race condition；TLA+ 也同样好用，他有时会把 Lean 和 TLA+ 结合起来排查 data flow、并发和状态管理的问题。他表示自己两门语言都不熟，但 Claude 都很擅长，因此这是发现人类可能注意不到的 bug 的实用方法，并追问 formal verification 是不是编码（至少是 bug finding）的未来。第二，一个 benchmark：Opus 5.5 与 Fable 5.1 各自把 HAProxy 从 C 移植到 Rust，两者都通过了几乎全部 HAProxy 测试，但 Opus 5.5 用时 9.5 小时（对方 12 小时），成本还低了 51%。

**Thariq, Claude Code at Anthropic, previously YC W20, SPC and the Media Lab**

A philosophy-of-building post: the right way to use model capabilities is not to ship 10x more features to production, but to spend more time understanding your users, running experiments, building prototypes and learning about things you do not understand, so that you ship things that actually work. Alongside it, a note to himself that 3D generation is a great capability for imagining your game coming to life, but you should first figure out how to make a good, satisfying game loop.

一篇关于构建哲学的帖子：正确使用 model capabilities 的方式不是向生产环境多塞 10 倍功能，而是花更多时间理解用户、做实验、搭原型、学习自己不懂的东西，从而发布真正能用的东西。同期他还自我提醒：3D generation 是让游戏想象成形的绝佳能力，但你得先想清楚怎么做出好玩、令人满足的 game loop。

**Aaron Levie, CEO of Box**

Two posts. First, on an insane day in AI where the frontier models became substantially cheaper (Opus 5.5 price cuts, GPT-6 Sol and Luna dropping token prices 50%), he argues the rate at which cost per task drops is unlike any technology in history, and every drop dramatically increases the use cases agents can serve: this is Jevons paradox applied to agents, driving broader diffusion of AI in the economy. Second, Box's test results with Opus 5.5 on complex enterprise knowledge work: 63% fewer tokens, 42% less verbosity, 30% faster versus Opus 5, plus task accuracy gains across four industry tests: financial due diligence +39%, cloud cost analysis +65%, client account analysis +17%, clinical diagnostics +15%, often using a fraction of the tokens of Opus 5.

两条帖子。第一，在这个前沿模型大幅降价的日子（Opus 5.5 降价、GPT-6 Sol 与 Luna token 价格下调 50%），他认为 AI 单任务成本下降的速度是历史上任何技术都不曾有过的，而每一次降价都会大幅增加 agent 可以覆盖的 use case：这是 Jevons paradox 在 agent 上的体现，将推动 AI 在经济中更广泛地扩散。第二，Box 用 Opus 5.5 测试复杂企业知识工作的结果：相比 Opus 5，token 减少 63%、verbosity 降低 42%、速度快 30%，四项行业测试的任务准确率也有提升：金融尽职调查 +39%、云成本分析 +65%、客户账户分析 +17%、临床诊断 +15%，而且往往只用了 Opus 5 的一小部分 token。
