## 一、今日要闻

> 按「可靠来源 + 信息量 + 与工程实践的相关性」筛选，本窗口资讯池以 arXiv 机器人论文为主，社区/产业类仅 5 条。

1. **[TinySDP：面向嵌入式机器人的实时半定规划求解器](https://arxiv.org/abs/2605.13748)**（⭐️ 8.0/10，本窗口最高分之一）— 首个专为嵌入式系统设计的半定规划（SDP）求解器，让微控制器能对**含非凸障碍约束**的问题跑实时 MPC：把半正定锥投影嵌入基于缓存的 Riccati-ADMM 求解器，配一个后验 rank-1 证书把松弛解转成显式几何保证。死胡同与动态避障基准上路径比最强基线最多缩短 73%，已在 Crazyflie 四旋翼上验证实时性。
2. **[世界-动作模型机器人学习与控制综述](https://arxiv.org/abs/2609.16074)**（⭐️ 8.0/10）— 系统梳理将「预测未来世界」与「生成可执行动作」耦合的 WAMs，划清它与传统世界模型、基于模型的 RL、动作条件视频生成、反应式 VLA 策略的边界，并给出表示/转移建模/动作接口/架构/数据模态的统一分类与评估协议。属综述，价值在框架而非新结果。
3. **[占用网络引导的自主机器人肾部分切除术](https://arxiv.org/abs/2609.16186)**（⭐️ 8.0/10）— 条件占用网络**全在物理仿真中训练**，从单视角部分点云推断完整三维解剖结构，并在组织被切割变形时维持术中跟踪；患者来源水凝胶体模上连续完成 8 次自主肿瘤切除、77 次电外科切割，全部阴性边缘，平均绝对边缘误差 1.61 ± 0.48 mm。⚠️ 仅体模实验，不能外推临床。
4. **[Flock 摄像头被曝硬编码凭证等安全漏洞](https://www.wired.com/story/hackers-flock-camera-data-shows-how-system-works/)**（⭐️ 7.0/10，[社区讨论](https://news.ycombinator.com/item?id=49726586)）— Wired 与 404 Media 联合报道：黑客入侵了自动车牌识别（ALPR）摄像头，暴露**硬编码 API 密钥**与**明文存储凭证**；该密钥可换到看起来能访问 Flock 服务器的新凭证。全美部署超 13 万台，今年已有 50 多个市县停用。社区批评其漏洞披露政策条款几乎堵死真实报告路径。
5. **[4B 模型生成查询计划，比 Postgres 快 81%](https://rohanbansal.com/qorl)**（⭐️ 7.0/10，[社区讨论](https://news.ycombinator.com/item?id=49731285)）— 作者用 4B 参数模型替代 Postgres 的启发式查询优化器，并从更大模型（Astra）蒸馏。社区普遍质疑基准条件（8GB 全内存数据集、受限 shared_buffers、预热查询、只读 SELECT）放大了结果，也担心过拟合。
6. **[美光展示业界首款 512GB DDR5 RDIMM](https://www.embedded.com/micron-develops-ultra-dense-512-gb-ddr5-memory-module/)**（⭐️ 7.0/10，本窗口唯一 EE/IC 直接资讯）— 已在多服务器平台演示，速度最高 9,200 MT/s，同时降低运行功耗。参考现役 256GB DDR5-6400 RDIMM 约 19,000 美元零售价，512GB 模块成本预计显著更高。来源摘要简短，无独立验证。
7. **[Mistral 与 Mozilla 合作，为 Firefox 带来私密多语言 AI 浏览](https://mistral.ai/news/mistral-x-mozilla/)**（⭐️ 7.0/10，[社区讨论](https://news.ycombinator.com/item?id=49723408)）— Firefox「Smart Window」支持上下文感知搜索、页面摘要、跨标签页记忆检索，先在法国与北美上线。官方称基于零数据保留政策，但**未说明本地推理与云端推理的架构界限**，社区批评点正在此。
8. **[拟人手学会用指尖行走并完成操作任务](https://arxiv.org/abs/2609.17172)**（⭐️ 7.0/10）— ETH Zurich 训练一只拟人机械手用**同一组手指**同时负责移动身体、支撑自重与操作环境：板载电源+算力（树莓派 + IMU + 电池）无缆自主运行，RL 在按硬件测量校准的仿真中训练，奖励函数针对手指长度不等专门设计。硬件上实现无缆爬行、转向、跌倒恢复，并在无视觉条件下依次敲键盘、借俯视视觉推物到目标位。硬件平台是宇树仿生灵巧手（20 个主动自由度、全直驱）。⚠️ 策略为任务专用，无转向时会向右漂移。
9. **[TARC：自适应控制频率的机器人强化学习框架](https://arxiv.org/abs/2510.23176)**（⭐️ 7.0/10）— 让策略**同时预测控制动作与动作施加时长**，在控制切换次数的软/硬约束下学习时间延展动作，从而在线调节控制频率。在 RC 赛车、Unitree Go1 与一个 VLA 模型仿真中，控制频率不到高频定频控制器一半而性能相当。
10. **[XRoboToolKit-T：触觉力控遥操作系统](https://arxiv.org/abs/2609.16437)**（⭐️ 7.0/10）— 用「stabilizer 触觉模块快速分析法向力分布并推断伪剪切力」做实时触觉辅助，再用「refiner 模块集成 VLA」依据触觉数据与任务描述优化动作；在抓取可变形橡胶移液管做液体转移、注射器插入血管训练垫等接触密集任务上验证。⚠️ 单篇预印本、摘要被截断、无同行评审与基准对比。
11. **[腕带压力传感器阵列实现全手姿态与接触力估计](https://arxiv.org/abs/2609.16518)**（⭐️ 7.0/10）— 环绕手腕的柔性电容阵列 + RNN，从肌肉收缩与肌腱位移产生的压力模式反推全手姿态与分布式接触力，**无需与皮肤电接触、手上不戴传感器**。单用户孤立运动平均手指关节 MAE 4.6°；4 名用户操作日常物体时每指接触力 R²=0.57，引入外部姿态信号后升至 0.75。
12. **[四旋翼安全新方法：逃逸感知控制屏障函数](https://arxiv.org/abs/2609.17292)**（⭐️ 7.0/10）— 指出输入受限系统的 CBF 几乎总是「只依赖状态」，在四旋翼上会认证**实际上来不及逃逸**的状态：该认证缺口宽度与接近速度成正比、与可达机体角速率上限成反比。作者在「状态 + 上一时刻输入」的增广对上定义逃逸屏障，给出闭式表达与最大可认证接近速度的解析逆，可嵌入预测控制器且不增加状态维度。550 组闭环实验中全部通过，对照的停止距离屏障在两类场景分别失败 15% / 25%。⚠️ 仅 13 状态仿真，无实机。

## 二、领域深读（机器人 · 嵌入式 · EE/IC · AI）

### 机器人

- **TinySDP：把「非凸约束下的实时优化」搬到 MCU 上。** 它的真正贡献不是「又一个 MPC」，而是在**资源受限的嵌入式目标上把半定规划做成实时可解**——用缓存 Riccati 结构吃 ADMM 的计算结构、再用 rank-1 证书把松弛解升回可用的几何保证。也就是说它同时解决了两件事：算力不够，以及非线性松弛解不可信。[来源](https://arxiv.org/abs/2605.13748)
  - ⚠️ 注意边界：验证平台是 Crazyflie 四旋翼，属学术验证；论文 73% 的路径缩短是与特定基线对比的结果，不能直接当性能承诺。

- **灵巧手四条串读（移动 · 容错 · 触觉 · 抓取）**：今日 arXiv 里灵巧手/手部方向同时出现了四条互补工作，值得合起来看——
  - **拟人手指尖行走**（ETH）：同一只 20 自由度全直驱手，既当腿又当手，任务专用 RL 策略 + 板载树莓派。[来源](https://arxiv.org/abs/2609.17172)
  - **并发式 [残差故障自适应 RFA](https://arxiv.org/abs/2609.17404)**：针对「运行时隐藏的命令通道关节故障」，保留一个冻结的健康教师策略提供标称行为，再训一个循环残差策略从本体感觉与命令响应史中推断纠正动作；关键工程手段是**故障注入域随机化（FIDR）**——随机化故障模式、受影响关节、严重程度、发生时间，并对近期表现差的模式加权采样。部署时控制器**不接收故障标签、不做控制器切换**，靠泛化兜住。
  - **触觉采集**：[XRoboToolKit-T](https://arxiv.org/abs/2609.16437) 指出行业痛点——现有遥操作数据采集**拿不到稳定高频的触觉反馈**，导致接触密集任务的数据质量受限。
  - **腕带式力感知**：[柔性电容腕带](https://arxiv.org/abs/2609.16518) 把传感器从手上挪到手腕，用肌肉/肌腱产生的压力模式反推全手姿态与接触力；单指 R²=0.57 说明「纯腕部信号估力」目前仍是中等精度，需外部姿态信号补强。

- **TARC：控制频率本身也是可学习的变量。** 定频控制器有个默认假设——为保证鲁棒性，控制频率往高取。TARC 让策略连「这个动作要持续多久」一起输出，在切换次数约束下优化，结果控制频率不到定频方案一半而性能相当。[来源](https://arxiv.org/abs/2510.23176)

- **逃逸感知 CBF：安全认证里的「来得及」问题。** 传统只依赖状态的屏障会认证那些「状态看着安全、但受角速率限制根本来不及减速」的情况；论文给出这个认证缺口宽度的闭式刻画（∝ 接近速度，∝ 1/角速率上限），并把屏障定义在「状态 + 上一时刻输入」的增广对上。[来源](https://arxiv.org/abs/2609.17292)

- **边角补充**：掌上双桨水下机器人（65mm / 34g，两桨垂直堆叠，PID + 差动推力俯仰、尾舵偏航，游速 13.9 体长/秒、跃出水面 1.6 体长高）[来源](https://arxiv.org/abs/2609.17240)——它把「差动推力替代控制舵面」做得很干净，可当控制分配的思路参考。另有 [ConGraspXL](https://arxiv.org/abs/2609.16319)（抓取约束的组合式可控合成：接近方向 / 接触区域 / 手腕轨迹 / 功能手姿，用掩码残差接口组合约束），属学术向，暂无落地证据。

### 嵌入式 / 硬件

- **Flock 摄像头事件：硬件产品安全的教科书式反例。** 关键在于漏洞的**性质**而非数量——**硬编码的 API 密钥**，以及**明文存储的凭证**。把设备部署在无人看护的公共场所，威胁模型里就必须包含「本地物理接触」；评论者的判断更狠：用现成的软硬件栈拼产品，攻击面扩大几乎是必然结果。[来源](https://www.wired.com/story/hackers-flock-camera-data-shows-how-system-works/)（[社区讨论](https://news.ycombinator.com/item?id=49726586)）

### EE / IC

- **[美光 512GB DDR5 RDIMM](https://www.embedded.com/micron-develops-ultra-dense-512-gb-ddr5-memory-module/)**：单条 512GB、9,200 MT/s，已在多服务器平台演示。技术上是把更多 DRAM 颗粒挂到同一条模组上（RDIMM 靠寄存器缓冲地址/控制信号换取容量），工程上真正的问题在成本与功耗——现役 256GB DDR5-6400 约 19,000 美元，512GB 的价格会显著抬高采用门槛。来源摘要较短，**无独立验证**，当作趋势记录而非结论。

### AI

- **[4B 模型生成查询计划](https://rohanbansal.com/qorl)：一条"小模型 + 蒸馏"的路线，和一场关于基准的争论。** 方法是训练 4B 模型替代 Postgres 启发式优化器，称计划快 81%，并从更大模型蒸馏。社区的反对集中在测试条件（全内存数据集、受限缓冲区、预热、只读负载）与过拟合风险，也有人认为 LLM 在此场景是「钝器」，更期待 AlphaGo 式的神经网络启发式方法。[社区讨论](https://news.ycombinator.com/item?id=49731285)

- **[Mistral × Mozilla](https://mistral.ai/news/mistral-x-mozilla/)：隐私叙事与架构透明度之间的落差。** 功能本身不新（对照 Chrome 的 Gemini Nano），争议点在官方**没说清本地推理与云端推理的界限**，社区因此质疑「零数据保留」不可验证。[社区讨论](https://news.ycombinator.com/item?id=49723408)

- **[Dream-RSI](https://arxiv.org/abs/2609.14858)：世界模型方向的又一步，但命名被质疑。** 让多个智能体在有限精炼步数内竞争式提升任务表现，并用历史回放模拟器做离策略评估以避免昂贵 rollout；多位评论者指出这更像对现有训练的优化，而非能永久自我改进的系统，且明显承接 Danijar Hafner 的 Dreamer 系列。[社区讨论](https://news.ycombinator.com/item?id=49726955)

- **[世界-动作模型综述](https://arxiv.org/abs/2609.16074)**：把 WAMs 的边界、分类体系与评估协议整理成一份可引用地图，并点出五个开放挑战（动作对齐、世界-动作分解、空间与多视角一致性、长时程记忆、面向闭环策略学习的神经仿真、高效推理）。[来源](https://arxiv.org/abs/2609.16074)
